Total Body Submersion — Home page

Static site, no build step. Upload this whole folder (index.html + assets/) to any static host:
  - Netlify: drag the folder onto app.netlify.com/drop
  - Vercel / Cloudflare Pages / GitHub Pages: deploy the folder as-is
  - cPanel / any web server: upload to public_html

Libraries load from CDN (pinned versions): GSAP 3.12.5 + ScrollTrigger, Lenis 1.1.13.
Fonts: Big Shoulders Display, Onest (Google Fonts).

Sound effects (assets/sfx/*.mp3) are real water recordings released under CC0 1.0
(public domain, no attribution required; licence text in assets/sfx/LICENSE-CC0.txt),
from the "40 CC0 water / splash / slime SFX" and "100 CC0 SFX" packs collected at
github.com/lavenderdotpet/CC0-Public-Domain-Sounds. Visitors can mute with the
equalizer button in the nav; the choice is remembered.

Placeholders to wire up: Login, Join Now, Register, Privacy Policy, Terms, Blogs, Donate
currently jump to on-page sections; point them at your real URLs.
Social links point to the networks' home pages; replace with TBS profile URLs.
